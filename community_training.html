▸ Project Command Center

Project Command Center — Community Service Simulator

You are the cadet project leader for a community clean-up event. The Project Command Center is a multi-stage interactive simulator that tests everything you have learned about planning and leading a community service project. Make the right decisions at each stage — define the project scope, write the plan, conduct a risk assessment, communicate with the civilian partner, allocate resources, respond to events on event day, and lead the debrief. Every choice affects your project success meters. Complete all stages successfully to earn the Project Command badge. Toggle on the community spirit music for an inspiring atmosphere.
